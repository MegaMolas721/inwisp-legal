# inwisp-legal

Páginas públicas requeridas por el trámite de publicación de la app OAuth del
proyecto InWisp (respaldo de configuraciones de routers MikroTik).

- `index.html` — página principal de la aplicación.
- `privacidad.html` — política de privacidad (incluye la cláusula de uso limitado
  de las APIs de Google).

No contiene código del sistema, ni credenciales, ni datos de la red: son dos
páginas estáticas sin JavaScript, sin cookies y sin recursos externos.

Publicado con GitHub Pages desde la raíz de la rama `main`.
